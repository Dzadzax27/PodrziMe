## PodrziMe_RS2

Seminarski rad iz predmeta Razvoj softvera 2 na Fakultetu informacijskih tehnologija u Mostaru

## Upute za pokretanje

Buildati docker komandom: docker-compose up --build -d

Pokrenuti docker komandom: docker-compose up

Extractovati file fit-build-2025-12-06-desktop.zip

Pokrenuti podrzime_admin.exe, te logovati se sa kredencijalima navedenim ispod

Extractovati fit-build-2025-12-06-mobile.zip

Nakon extractovanja, na pokrenuti emulator uređaj prenijeti fajl "app-release.apk" i sačekati da se aplikacija instalira

Nakon što je aplikacija instalirana, pokrenuti je i unijeti mobilne kredencijale koji se mogu pronaći u ovom readme-u skrolanjem

## RabbitMQ
